# Tourism Website

Welcome to the Tourism Website repository! This project is designed to showcase various tourist attractions, hotels, and fun activities in a city. It aims to provide a user-friendly experience to potential travelers with helpful information and images of key locations.

## Features

- Detailed pages for various tourist attractions (e.g., Gateway of India, CST, Elephanta Caves)
- Gallery to view images of popular places
- Links to hotels and heritage sites
- Responsive design to cater to different screen sizes

## Project Structure

The project consists of the following main files:

- `index.html`: The homepage of the website
- `banganga.html`, `crawford-market.html`, `cst.html`, etc.: Individual pages for tourist attractions
- `style.css`: CSS file for styling the website
- `gallery.html`: A page displaying a gallery of images from different tourist sites

## Technologies Used

- **HTML**: For structure and content
- **CSS**: For styling and design
